Приборы учёта (ПИУ)

Внимание! Показания принимаются строго с 20 по 25 число каждого месяца.
1

Снимите показания

Записывайте только целую часть расхода (чёрные цифры на циферблате), красные цифры (литры) учитывать не нужно.

2

Выберите способ

Вы можете передать данные онлайн через Личный Кабинет КВЦ или через мобильное приложение.

3

Альтернативный вариант

Если нет интернета, опустите бумажный талон с показаниями в специальный ящик ТСЖ в вашем подъезде.
